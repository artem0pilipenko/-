# Информатика для первокурсника (как пользоваться гайдом)

## О чем вообще этот проект?
Этот репозиторий я собрал в рамках лабы по ГИТу. Я решительно не понимаю, зачем она нужна, но информация здесь может быть полезной кому-то. Цель простая — накидать понятный справочник по базовой информатике, без лишней заумной воды из учебников, которую никто никогда не читает.

Выбрал тему **«Системы счисления»**. Это основа, на которой вся компьютерная логика и держится. 

**Автор:** Пилипенко Артём Андреевич 1-курс ПГУПС ИВБ-615

## Что внутри (структура)
Справочник разбит на несколько небольших файлов, так удобнее читать:
*   [ glossary.md ](glossary.md) — тут собрал 8 терминов.
*   [ examples.md ](examples.md) — три примера перевода чисел с подробным разбором.
*   [ sources.md ](sources.md) — пара ссылок на сайты с информацией.
*   [ questions.md ](questions.md) — небольшой тестик.

---

## Как этим справочником пользоваться?
Советую читать по порядку. 
Сначала открываем `glossary.md` — там чисто разобраться, в чем вообще разница между позиционными и непозиционными системами. Когда в голове уложится, можно переходить к `examples.md`, там как раз алгоритмы перевода расписаны. Лучше всего взять черновик и параллельно попробовать решить примеры самому, сверяясь с ответами. Ну а в самом конце открывайте `questions.md` — если на все три вопроса ответите без подглядывания, значит вы пережили это! Если где-то запутались, в `sources.md` есть ссылки, там можно почитать подробнее, и начать всё сначала.
